# Omamu

**An Omarchy-inspired muOS theme** built for the Anbernic RG35XX H at 640×480.

Omamu brings Omarchy's restrained workstation aesthetic to a handheld frontend: near-black surfaces, warm cream text, amber focus states, square edges, compact typography, a technical grid, and JetBrains Mono. It is an original theme for muOS, not a port of the Omarchy desktop environment.

## What's included

- Global palette for backgrounds, headers, footers, lists, dialogs, keyboard, notifications, volume/brightness bars and counters.
- RG35XX H-specific schemes for Main Menu, Explore Content, Configuration, Customisation and Pickles/Retro settings.
- Original per-screen grid wallpapers and a matching theme preview, generated during CI.
- Original amber line glyphs for the main-menu destinations.
- JetBrains Mono bundled under the SIL Open Font License 1.1; the license ships inside the theme package.
- Automated metadata, INI syntax, asset and archive-layout checks.

## Preview on Windows (no device needed)

Open the standalone [Omamu Preview](preview/index.html) source in GitHub, then use **Download raw file** and save it as `omamu-preview.html`. Double-click the saved file to open it in Edge, Chrome or Firefox; it runs locally and needs no installation or internet connection. It simulates the RG35XX H screen at 640×480 and lets you switch screens, adjust text size/right padding, test clock and battery colours, check inactive icons, toggle dividers, and test long labels. Use **Muat INI** to load a scheme file and preview selected values. This is a visual approximation, not the native muOS renderer, so verify the final result on-device when possible.

## Build with GitHub Actions

1. Open [Actions → Build muOS theme](https://github.com/insomdroid/Omamu/actions/workflows/build-theme.yml).
2. Select **Run workflow** on branch `main`, or push a commit to `main`.
3. Open the successful run and download the `omamu-muxthm` artifact.
4. Extract the downloaded artifact ZIP to get `Omamu.muxthm`.

The package stores theme files directly at the archive root, as required by the muOS theme packaging guide.

## Install

1. Copy `Omamu.muxthm` to the `ARCHIVE` folder on SD1 or SD2.
2. On the device, open **Applications → Archive Manager** and select the file.
3. Open **Configuration → Customisation → Theme Picker** and activate Omamu.

Keep your current theme available until you have confirmed the new theme behaves correctly. CI checks structure and syntax, but only the device can confirm how every frontend element renders on the installed muOS version. If an element looks wrong, send a screenshot and the muOS version so its scheme can be adjusted.

## Project layout

- `scheme/global.ini`: shared theme palette and common UI styling.
- `640x480/scheme/`: resolution defaults and per-screen overrides.
- `640x480/image/wall/`: generated screen-specific wallpapers.
- `640x480/glyph/muxlaunch/`: original main-menu SVG glyphs.
- `640x480/font/`: downloaded JetBrains Mono font and OFL license during CI.
- `scripts/build_theme.py`: validates files, generates artwork, and packages the theme.
- `.github/workflows/build-theme.yml`: reproducible build and artifact upload.
