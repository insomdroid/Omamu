# Omamu

**Omarchy-inspired muOS theme**, designed first for the Anbernic RG35XX H at 640×480.

Omamu translates the visual language of a focused Linux desktop into a handheld frontend: near-black surfaces, restrained amber accents, warm off-white text, compact technical typography, and a subtle grid wallpaper. It does not attempt to run Omarchy or replace muOS components.

## Build with GitHub Actions

1. Open **Actions** in this repository.
2. Select **Build muOS theme**.
3. Select **Run workflow** (or push a change to `main`).
4. Download the `omamu-muxthm` artifact from the completed run.

The workflow creates `Omamu.muxthm`. The package contains the theme files directly at its archive root, as required by the muOS theme packaging guide.

## Install

1. Download `Omamu.muxthm` from the workflow artifact and copy it to the `ARCHIVE` folder on SD1 or SD2.
2. On the device, open **Applications → Archive Manager** and select the file.
3. Open **Configuration → Customisation → Theme Picker** and activate Omamu.

Keep your existing theme available until Omamu has been tested on-device. This repository's CI validates packaging and basic asset structure; it cannot replace testing on the actual muOS version and hardware.

## Project layout

- `scheme/global.ini`: conservative global theme settings.
- `640x480/`: RG35XX H resolution-specific assets and preview generated by CI.
- `scripts/build_theme.py`: validates metadata and creates the preview, wallpaper, and `.muxthm` archive.
- `.github/workflows/build-theme.yml`: runs the build and uploads the package as an artifact.

## Design and licensing

Omamu is an original, Omarchy-inspired design for muOS; it is not an official Omarchy or muOS project. No third-party font or icon pack is bundled in this initial scaffold. The generated artwork is created by the build script.
