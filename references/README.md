# References

Tempat menyimpan referensi untuk pengembangan tema Omamu.

Gunakan folder ini untuk mengumpulkan tautan dokumentasi resmi, contoh tema MustardOS/muOS, referensi desain, serta catatan teknis yang membantu pengembangan.

## Format yang disarankan

Untuk setiap referensi, catat:
- **Nama:** judul atau nama sumber
- **URL:** tautan sumber asli
- **Kegunaan:** bagian tema yang dirujuk
- **Catatan:** detail penting atau batasan lisensi, jika ada

Simpan berkas pendukung di folder ini jika lisensinya mengizinkan. Jangan menyalin aset pihak lain tanpa memeriksa izin penggunaannya.
